# Dexatron privacy policies

Public GitHub Pages site for Dexatron product privacy policies.

- Hub: `index.html`
- DEXATRON VR: `vr/index.html`
- DEXABOT and Quizbot: `dexabot/index.html`

To rename the VR game, search and replace `DEXATRON VR` in `vr/index.html`.

To add a contact email, replace `[CONTACT EMAIL]` on the VR and bot policy pages.

GitHub Pages should be served from the `main` branch, site root.

https://dexatroncrypto-sys.github.io/Privacy/
